# cross-file-contract

First perform a deterministic operation renaming parseQty to parseQuantity in the quantity export and quote import/call. Then in a dependent involved operation, change parseQuantity(value) to return {units,source}. Accept nonnegative safe integer numbers with source="number", or trimmed nonempty strings of ASCII digits whose parsed value is a nonnegative safe integer with source="string". Reject all other inputs with RangeError. Leading zeros are valid. Update quote(priceCents,rawQty) to consume the new object and return {quantity:units,subtotalCents:priceCents*units}. priceCents must be a nonnegative safe integer and the product must be safe, otherwise RangeError.
In a separate simple operation, update receipt to consume the new quote object and return "Q units: C cents" with Q replaced by quantity and C by subtotalCents; for example receipt(125,"2") returns "2 units: 250 cents". This operation must depend on and read the updated quote module. Keep its public signature. No old parseQty export remains. Set config version=2 preserving keep using deterministic edits. Preserve unrelated files.
