Name avatar

A stable monogram fallback with a deterministic hue, configurable size, title, and decorative mode.

Monogram derivation

Trim surrounding whitespace, split on whitespace, then use the first character of the first and last word. A single word uses its first two characters. Convert to uppercase.

Hue derivation

Fold each character code with hash = (hash × 31 + code) modulo 2³². Hue is hash modulo 360. Background uses 55% saturation / 88% lightness; foreground uses 55% / 28%.

Accessibility

Visible names have accessible labels and tooltips. Decorative avatars use aria-hidden=true. Callers can provide a custom title and inline style.
