Design system

Status surface

Full-page or inline status surfaces for loading, error, empty, and not-found states.

Variants

◌

Loading workspace

Workspace content will appear when loading completes.

variant: loading · role=status · as=main

!

Could not load workspace

Check your connection, then retry.

variant: error · role=alert · as=section

▣

No sections yet

Create a section or import a markdown file to start.

variant: empty · role=status · as=section

⌕

Section not found

This section may have moved or been deleted.

Return to graph

variant: notFound · role=status · as=main

Contract

  • Loading, empty, and not-found announce politely with role=status.
  • Error uses role=alert.
  • Main surfaces fill the viewport; sections fit inside a page.
  • Actions use a clear recovery verb.
  • Optional chrome can remain visible above the status content.
