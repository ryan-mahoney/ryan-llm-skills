Node state

  • Selection state outranks current and unplaced state.
  • Current cards use identity styling; unplaced cards use a dashed boundary.
  • Freshness appears only when both edit timestamp and editor identity are present.
  • Unknown comment totals remain hidden.
  • Non-connectable document types omit connection handles.
  • Live position is labeled as a temporary move.
