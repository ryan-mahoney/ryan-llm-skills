Light and dark

Both themes render from one rule set. Tags and statuses map to tokens, not fixed colors, so the theme switcher recolors every example without per-theme overrides.

Tag to token
  • Blog — --ds-accent
  • Newsletter — --ds-info
  • Social — --ds-ident
  • Press — --ds-unsaved
Status to pill
  • Draft — ds-pill--saving
  • Needs edits — ds-pill--unsaved
  • Done — ds-pill--saved
Mix against transparent

Translucent fills mix against transparent, never #fff, and hairlines use --ds-line / --ds-line-2. Both themes then render from one rule set.

Accessibility

  • The view switcher is a role=group named “Calendar view”; each button reports aria-pressed for the active view.
  • Nav buttons expose aria-label: Today, Previous, Next.
  • The range label is announced when view or step changes.
  • Each record is keyboard focusable and named with title, status, and its scheduled or unscheduled date.
  • The month grid is a table with weekday column headers and a month/year label.
  • The preview dialog is labelled by its card title, closes on Escape, and returns focus to its opener.

Keyboard

keyboard model

KeyAction
Arrow Left / RightReschedule the focused record by one day, back or forward.
Arrow Up / DownReschedule the focused record by seven days, back or forward.
Enter / SpaceOpen the preview for the focused record.
Delete / BackspaceUnschedule the focused record. It returns to the Unscheduled rail.
EscapeClose the preview.

Key handling is suppressed while focus is in an input, textarea, or contentEditable, so editing prose never reschedules a record.

Responsive

  • Mobile first: the Unscheduled rail stacks below the calendar by default and moves beside it at 900px and up.
  • The week and 5-day column grid keeps a minimum column width and scrolls horizontally rather than collapsing.
  • The topbar and toolbar wrap when space runs out.
  • No fixed-pixel widths force the page into horizontal overflow at 320px.
