One registry, mixed against transparent

One DOCUMENT_TYPES registry drives both badges and locators. There is no second type-to-color map, so a badge and its locator can never disagree.

Tints mix against transparent, never #fff, and hairlines use --ds-line / --ds-line-2, so both themes render from one rule set.

Accessibility

  • The input keeps DOM focus while navigating. It is a role=combobox with aria-autocomplete=list and aria-activedescendant pointing at the selected option, cleared when none is selected.
  • Each result row is a role=option with aria-selected. Options are never focused; selection moves through aria-activedescendant.
  • The results container is a role=listbox; the facet rail is a role=group named “Filter by type”.
  • The result count sits in an aria-live=polite element, so filtering announces the new total.
  • The overlay is an aria-modal dialog labelled “Search”. It closes on Escape and restores focus to the trigger.

Responsive

  • Mobile first: the facet rail becomes a horizontal-scroll strip instead of a sidebar column.
  • The appbar brand and secondary chrome hide at narrow widths; the search field keeps the full row.
  • The overlay holds a max-height and scrolls its results internally rather than growing the page.
  • No fixed-pixel widths force body-level horizontal overflow at 320px.
