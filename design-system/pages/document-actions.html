Output styles

Each output format can carry a custom style. Assignment is per format. Markdown never carries an output style. A binding that no longer resolves silently falls back to the renderer default.

Output styles menu item

Output styles drawer

Output styles

Assign a custom style per output format. Markdown never carries an output style.

  • HTML Default HTML
  • PDF Academic · CSS · Organization
  • DOCX Default DOCX
  • Markdown No output style

Binding states

Synced document assignment

A synced document can only bind organization-scoped styles. Private scope is disabled; share a style with the organization to make it eligible. With no organization-scoped styles, Choose is disabled.

Style scope
  • HTML No eligible styles
  • PDF No eligible styles
  • DOCX No eligible styles

Unresolved bindings fall back to Default

A narrowed or deactivated binding is omitted from reads. The format renders with its Default style; the stored binding remains until cleared or reassigned.
