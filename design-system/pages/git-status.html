Design system

Git status

One line of readings on the canvas above the Assistant. Color lives in the icon; words carry meaning. Permanent detail moves to hover titles.

Color key

Five tones encode status. Every tone is backed by a word and icon shape, so meaning survives without color.

Tones

  • Clean
  • Changed
  • Ahead
  • Behind
  • Conflict

Section states

The resting line keeps status concise. Hover titles carry permanent detail such as the file breakdown, base ref, and stale notes.

Composed line

worktreeClean0 changed files
worktreeChanged3 changed files
mainBehind2 commits behind
branchAhead1 commit ahead
branchConflictRebase blocked

Actions

Actions enable only when preconditions hold. Disabled actions keep a specific reason in their title.

Rebase main

Ready: Branch is clean and current.

Blocked: Commit or stash local changes first.

Conflict: Resolve the current rebase before retrying.

Create PR

Ready: Branch is ahead and has an upstream.

Blocked: Push the branch before creating a PR.

No changes: Add a commit before creating a PR.

Disabled actions keep their reason

A blocked Rebase or Create PR stays visible and names the missing precondition.
