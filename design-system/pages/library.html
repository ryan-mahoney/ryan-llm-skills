Design system

Library

The Library holds reusable assets. These never appear in the Open-document list and are never canvas nodes — they are building blocks an author attaches to documents.

Export styles are the first documented slice. Skills and support files are future tenants of this surface.

Style library

Only user-created styles are listed, grouped by output format. Each row carries a FORMAT · STYLE chip, a scope pill, and a used-by count. Built-in renderer defaults are the absence of a style and are never listed here.
