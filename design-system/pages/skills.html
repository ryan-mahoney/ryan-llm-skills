Design system

Skills

Skills are saved instructions the assistant can run on your writing. System skills ship with Restory; user skills are editable. Run one by name from the assistant with a slash, such as /tighten.

Skills management

Filter the skill library by scope or source, inspect a skill, edit your own, or remix a system skill. The assistant drafts proposals for review. This local example does not call workspace APIs.

Scope pills

Scope tells the assistant what information a skill may read.

scope variants

▤ Section⌘ Document⇧ Output
  • Section — Operates on the body of the section you have open.
  • Document — Operates across the whole reading-order graph.
  • Output — Operates on the assembled draft you would export.
