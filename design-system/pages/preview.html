Opening

Re-Story makes a long draft navigable by turning its order into a visible graph. Every edit moves through that structure, so the writer can see what changed and where it belongs.

Why a separate surface

Editing is structural. Reading is linear. Splitting the two keeps each task clear.

What this surface does

  • Section order follows graph traversal.
  • Unlinked sections appear after ordered sections.
  • Unsafe HTML is removed before rendering.
The order of the parts is a promise to the reader.

Inline code looks like assemble(sections) in prose.

Themed editor

The editor renders on the same paper surface as the preview and scales with the text-size control.
