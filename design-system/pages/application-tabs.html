Design system

Application tabs

Tabs represent open documents and sections. This catalog page shows strip geometry, state vocabulary, empty chrome, and keyboard behavior.

One tab per open document, file, or project. Tabs sit directly on --ds-chrome; the active tab stays neutral and marks selection with an indigo --ds-accent underline.

Tab strip

The window strip is a horizontally scrollable baseline strip with discrete tab children. A hairline baseline and 1px separators divide inactive tabs; the active tab uses an indigo underline, and separators beside active or hovered tabs fade. Labels truncate when space is limited. Product tabs keep 44px touch targets on mobile.

Product tabs use the default state today. The vocabulary documents one leading glyph plus one functional color; shape and text back up color. Running and attention motion stop when reduced motion is requested.

Section editor tabs

A section editor strip shows open section files in the active document. The active tab stays visually distinct, supports close buttons, and keeps a minimum hit area.

Keyboard behavior

Tab, Enter, Escape

Tab moves between controls. Enter activates the focused tab or close control. Escape closes a menu or dialog opened from the strip. Close controls are separate buttons with file-specific accessible names.
