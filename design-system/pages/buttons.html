Design system

Buttons

Buttons carry product intent. One primary per view, ghost for everything else, icon-only targets for repeated chrome actions, and destructive labels that repeat the verb and object.

Primary action

One primary per view. Primary uses --ds-accent-fill with white label text.

Primary action

Go action

Green marks the single forward commit that moves work ahead. Never pair it with another primary.

Go action

Secondary action

Quiet chrome background; use it for the next-best action when the primary already belongs to the main commit.

Secondary action

Icon-only buttons

Icon-only controls need a clear accessible name and tooltip. Reserve them for universal chrome actions.

Icon-only buttons

Touch targets: at least 44×44px.

Destructive action

Repeat the verb and object in destructive labels. Red text marks the destructive outcome.

Destructive action

Sizes

Default 38px for primary actions and forms; small 34px for dense rows; icon 30px for chrome targets.

Sizes

States

Hover uses chrome-hi. Focus uses a 2px accent outline with 2px offset. Disabled controls show reduced emphasis and cannot activate.

States
