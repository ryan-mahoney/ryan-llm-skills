Design System

Re-Story is a structured writing tool for authors: a graph for organizing sections, a markdown editor for drafting, and an assistant for reshaping prose. This system keeps those surfaces consistent as the product grows.

Purpose

Define the shared visual language for workspace chrome, editing tools, graph canvas, preview, and assistant interactions.
Tie decisions to selecting a workspace, arranging sections, editing markdown, and reviewing output.
Keep the page register aligned with navigation and examples.

Principles

Separate identity from action

Green marks Re-Story and the current place. Indigo marks interactive work: links, commit actions, focus rings, and active controls.

Keep writing surfaces dense and calm

Borders and spacing organize editorial information. Shadows are reserved for overlays that truly float.

Make state readable without guessing

Color is backed by text, shape, and accessible semantics.

Use real product behavior

Examples reflect workspace picking, graph organization, markdown editing, preview, and assistant flows.

Pages

Foundations cover color, typography, layout, buttons, forms, data, overlays, and feedback. Product surfaces cover navigation, document actions, graph, preview, search, sequence, plan, and collaboration.
