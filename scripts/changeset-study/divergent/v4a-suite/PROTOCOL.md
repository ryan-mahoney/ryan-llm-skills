# V4A writer pilot

This pilot separates encoding settled edits from choosing an implementation. All 12 fixtures are small synthetic cases, not mined commits or a replay of the earlier three-task study. Two observations per condition are a capability screen, not evidence of 95% reliability.

The encoding track contains eight fixtures: seven positive edit cases and one explicit-refusal case. DeepSeek Flash with thinking disabled produces V4A; DeepSeek Flash, Muse Spark Contributor with high reasoning, and MiMo V2.6 Pro with configured medium produce executable JSON changesets. The implementation track contains four small multi-file goals and uses JSON for the same three models. MiMo's configured medium setting enables thinking; its provider does not expose a distinct medium effort setting. No Sol model participates.

Each cell receives the complete original source map, allowed and protected paths, and either a settled instruction containing the requested edits or an implementation goal. Gold files, reference patches, and private checks stay out of model inputs. There are no tools, source lookups, delegated writers, or retries. Repeat two reverses the entire fixed order of repeat one. All 88 calls run sequentially.

## Limits and freezing

Each serialized SDK context must fit 32 KiB. This byte guard is conservative relative to a token limit. Every fixture and format is checked before freezing. Each call permits 8,192 output tokens and 120 seconds; each private behavior check permits five seconds. The suite permits at most 88 calls and $5 of charged cost plus outstanding reservations, including the proposed next reservation. The canonical existing $50 ledger remains authoritative and is never reset. Ordinary cell failures are retained and do not stop later cells; integrity and budget failures stop execution.

`runner.mjs prepare --output <new-adjacent-output> --ledger <existing-ledger> --sdk <installed-sdk-root>` snapshots the executable study, changeset engine, research grading backend, and actual SDK dependency tree. The manifest retains their inventories, Node hash, revision, model metadata, source and private-check identities, schedule, and preflight sizes. Saved snapshot paths are relative to the output root; the canonical ledger is an execution-local absolute path. Run the frozen runner's `verify --output <output>` before its `run --output <output>`. Execution pins SDK imports internally to the snapshot and uses normal credential resolution without saving credentials. Preparation performs no inference. Live execution follows independent review, a committed freeze, and the coordinator's release within the already authorized research budget.

## Evaluation

Primary parsing is strict JSON.parse for JSON and the exact V4A envelope for V4A. A separate lenient V4A wrapper diagnostic never upgrades the primary result. A refusal must be an explicit `REFUSE: reason`; expected refusal is scored separately from edit cases, and unexpected refusal fails.

Parsing, path ownership, application, ambiguity, syntax, and correctness are distinct gates. JSON is compiled and applied on a private workspace before syntax checking; compiler-added writes and dependencies are recorded. V4A uses the guarded compatible adapter described in its provenance documentation, including its explicit byte-preservation departures from upstream. Neither format receives silent whitespace, string, comment, or AST normalization. Valid whole-file replacements remain allowed, and output byte volume is recorded.

Encoding correctness requires exact gold source bytes. Implementation correctness requires the private behavior check and preserved protected files; exact reference equality is only diagnostic. Changed JavaScript and JSON receive separate syntax checks. Private behavior runs through the existing read-only sandbox grader and must emit its completion marker; an early successful process exit cannot pass. Applied but incorrect or syntactically invalid candidates remain retained and visibly fail qualification.

Each cell retains its input, raw output, requests, responses, receipts, candidate map, evaluation, and result. Sent calls are counted from request reservations and joined to the canonical ledger, receipts, and responses. Missing settlement evidence retains unknown charged cost and outstanding exposure and stops the suite. The reproducible report groups tracks, formats, selectors, and repeats; it reports separate gate denominators, refusals, applied-incorrect outputs, compiler assistance, latency, token categories, receipt costs, and output bytes. Private grading time is included only in total cell time, separately from generation latency. Model capacity and provider wire differences are retained rather than described as identical enforcement. This pilot makes no whole-workflow efficiency or general model-ranking claim.
